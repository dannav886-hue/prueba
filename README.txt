URBANBITE - PAGINA DE COMIDA RAPIDA

Archivos:
- index.html  -> pagina principal
- styles.css  -> estilos, animaciones y diseño responsive

COMO ABRIR:
1. Descomprime la carpeta.
2. Abre "index.html" con Chrome, Edge, Firefox u otro navegador.
3. No necesitas instalar Node, XAMPP ni ningún servidor.

FUNCIONES INCLUIDAS:
- Diseño responsive para PC y celular.
- Menú con filtros por categoría.
- Carrito lateral funcional.
- Contador de productos.
- Agregar/quitar cantidades.
- Combo del día.
- Animaciones y efectos hover.

NOTA:
La página es una demo frontend. El botón "Confirmar pedido" no procesa pagos ni envía pedidos a un restaurante real.
